第 1 章系统入门#

1.1登录#

启动「易盛金融管理终端」客户端（本手册以 9.3.8 版为准），在登录窗口录入以下信息：

项目说明
用户编号由公司统一开立，入职时申请
交易密码与公司电脑密码一致
管理前置默认配置，无需修改
SSL 加密不勾选
记住密码按个人习惯，公共电脑不建议勾选

点击【登录】进入系统。

注意登录失败时，优先排查两项：密码是否与公司电脑密码同步；管理前置配置是否被改动。

1.2主界面与菜单#

登录后进入欢迎页，顶部为系统功能菜单栏。菜单按功能划分——处理业务时先判定事项所属类别，再定位至对应菜单：

菜单功能定位常见场景
本地配置本机显示与操作习惯设置调整列表显示、界面布局
基础数据品种、币种、银行等主数据查询查询可交易品种
客户管理客户资料相关功能开户录入、客户银行、关系人、税务信息
参数管理费率模板与参数模板客户手续费调整 → 手续费模板

其余菜单与开户环节关联较小，本手册仅在涉及处说明（审核使用 其他信息 → 待审核管理）。

第四步：保存（两步，缺一不可）

1 每个子表（地址 / 手机 / 邮箱 / 证件 / 交易分组）填写完毕，点击子表自身的【保存】。
2 全部页签填写完毕后，点击录入页顶部【保存(S)】——整单方可生效。
风险关键提示：联系信息和证件信息保存之后，务必再点击客户信息的保存按钮，否则子表信息的保存不生效。勾选顶部"保存后跳转"后，保存成功将自动返回客户列表。

批量修改客户资料：必须使用「导出多表」

如需采用模版导出方式批量修改客户资料并重新导入，须在【导入导出】菜单中选择「导出多表」——客户信息由多张关联表构成，使用「导出单表」再导入将因表间关联缺失而报错。

注意批量导入（uploader）通用规则：仅支持新增与修改，不支持删除——导入前请确认模版中未误改其他记录。

2.2客户银行#

菜单位置：客户管理 → 客户银行。打开后为客户银行列表页，点击顶部【增加(A)】录入银行账户。

风险前置条件：录入银行信息前，客户信息必须先审批通过（不只是保存），否则"客户账号"下拉无法选中该客户。

录入规则：一个账号 × 一个币种 = 一条记录

客户银行一次仅能录入一个账号的一个币种。同一客户持有 HKD、CNY、USD 等多个币种账户时，须逐条录入。

提示

多币种/多账户批量场景：先录入一条币种账户 → 经列表页顶部【批量导入 → 模版导出】导出 Excel 模版 → 利用已录入的信息在模版中新增其余记录 → 「文件导入」传回。

批量导入（uploader）仅支持新增与修改，不支持删除——使用前请确认模版中未误改其他记录。

2.4客户税务信息#

风险前置条件：录入税务信息前，客户信息必须先审批通过，否则"客户账号"下拉无法选中该客户。

第 3 章审核#

全部录入/修改操作保存后，均进入待审核队列，由审核岗复核通过后正式生效。

风险录入与审核不得为同一人。若审核时选中包含本人提交的记录，【确认】键无法点击，系统提示"包含 X 条自己提交的，无法进行批量审核"。

3.1审核入口#

菜单位置：其他信息 → 待审核管理。默认按当日日期查询，可调整开始/结束日期筛选。

列含义
操作类型A(新增) / M(修改)
操作内容涉及的客户及资料（如 [客户账号:01100018]）
审核状态N(未审核) / 审核通过 / 审核不通过
操作人 / 操作时间录入人及其提交时间

3.2审核操作#

双击打开一笔待审记录，进入详情页：

  1. 被修改之处以红色高亮显示——审核员聚焦红字字段，对照开户表格核对即可。
  2. 底部为审批区：审核流号、协议名称、备注、【审核通过】【审核不通过】【撤回】。

核对要点

按团队核对清单执行，核对标准即第 2 章各节录入清单：

审核对象对照章节
客户基本信息（三个页签 + 联系/证件子表）2.1 客户信息
银行账户（币种、本外币/境内外标示、日期）2.2 客户银行
关系人（类型是否齐全、证件到期日）2.3 客户关系人
税务信息（关系人名称、辖区、TIN）2.4 客户税务信息

审批动作

动作说明
审核通过备注可留空，单据生效
审核不通过备注必填——按实际情况写明退回原因，以备后续审计核查
撤回仅操作人本人可撤回其提交的记录
风险新开户先审后建：新开户须先审批通过「客户信息」，才能新增【客户银行】【客户税务信息】【客户关系人】——这三个子模块的"客户账号"下拉只会列出已审批通过的客户。若客户信息被撤回或审核不通过，下拉里就选不到该客户，需先走完客户信息审核流程。
提示操作员自救：提交后若自行发现录入有误，无需等待审核退回——至待审核管理打开该笔详情页，点击底部【撤回】，修改后重新保存即可。

亦可在列表页勾选多笔，使用顶部【审核通过】/【审核不通过】批量审批。

3.3客户资料修改通知#

客户资料修改并审核通过后，如需正式告知客户"资料已更新"，可在审核时勾选通知选项，由系统把资料修改通知发送给客户。

操作步骤

1 菜单位置：其他信息 → 待审核管理，找到该客户的修改申请（操作类型 M(修改)）。
2 双击打开，进入审核详情页。
3 勾选页面左上角的【发送资料修改通知】复选框（位置在选项卡下方、客户账号栏的上方）。
4 核对无误后，点击页面底部【审核通过】——通知即发送给客户。
提示勾选与否只决定"是否给客户发通知"，不影响单据生效：不勾选时审核通过后单据照常生效，只是不发通知。通知是否已发出，可到 其他信息 → 邮件管理 核对（见 4.4）。

3.4退回与重新提交#

1 审核不通过 → 单据在待审核管理中状态变更为「审核不通过」，备注载明退回原因。
2 录入人按退回原因修改对应资料。
3 重新保存 → 单据再次进入待审核队列，等待复审。

第 4 章日常维护操作#

本章覆盖开户后的日常任务——修改手续费、调整可交易品种、查询日志、查询邮件，按"会用"的颗粒度编写：入口 + 关键步骤 + 注意事项。

4.1修改手续费（手续费模板）#

菜单位置：参数管理 → 手续费模板。

机制：每个客户开户时均被分配一个手续费模板编号（如 C0000、GC001…），修改某客户的手续费即修改其对应模板内容。若客户存在特殊手续费（专为客户而设），则为其新建专属模板（存量客户除外）。

操作步骤

1 查询该客户是否已分配专属模板编号（客户管理 → 客户信息 → 基础信息 → 特殊手续费）；若无，则为其新建模板。
2 在手续费模板界面，通过【批量导入 → 模版导出】导出该客户当前绑定的基础手续费模板。
3 在导出的 Excel 中修改费率数值——模板已含成交来源、计算方式、币种等参数配置，无需另行指定。
4 通过【批量导入 → 文件导入】将修改后的模板导入系统。
5 返回 客户信息 → 基础信息 → 特殊手续费，将该模板编号绑定至客户——完成绑定后新费率方可生效。
注意界面顶部三条注释：① 计算方式为空的行，保存时将被删除（默认模板 DEFAULT 的参数不允许删除）；② 锁仓比例与计算方式无关；③ 模板参数设置完成后，务必点击保存按钮方完成设置。
风险品种代码可能多于一个：同一品种可能存在 F(Futures 期货) / O(Options 期权) 之分，或分属不同交易所。修改前务必确认目标行；不确定时请咨询业务侧或 ops_etd，切勿臆测。

4.2调整可交易品种（品种组管理）#

菜单位置：基础数据 → 品种组管理。客户可交易的品种由其所属品种组决定（开户时在客户信息中指定品种组）。

界面三区

区域内容
左侧分组编号列表（A、ACMENIY、ALL、STD…）
中间已分配品种——该品种组当前包含的品种（交易所编码 + 品种类型 + 品种编号）
右侧未分配品种——尚未归入该组的品种

操作

操作步骤
分配（加入品种）在右侧"未分配品种"勾选品种编号 → 点击下方【分配】
取消分配（移出品种）在中间"已分配品种"勾选品种编号 → 点击下方【取消分配】
注意品种组修改须经审核——操作后进入待审核队列，复核通过方生效（见第 3 章）。请注意：改动品种组将影响所有使用该组的客户，操作前须确认影响范围。

4.3查看操作日志#

菜单位置：其他信息 → 操作日志。用于查询操作痕迹，即"何人于何时修改了何种内容"。

  • 按开始/结束日期圈定时间范围。
  • 以日志类型筛选：9(登陆日志)、1(用户基础信息)、2(用户分配信息)、Z(其他日志，含导入导出记录)等。
  • 关键列：客户账号（改动对象）、操作人、操作时间、日志内容（具体改动，如 Mod_Table / Add_Table 及字段变化）。
提示典型场景：客户资料被误改且无法确认操作人 → 输入客户账号与日期范围，按日志内容中的 Mod_Table 记录定位操作人。

4.4查看邮件发送状态（邮件管理）#

菜单位置：其他信息 → 邮件管理。系统发出的全部邮件（结算单、资料更改通知等）均在此留痕。

  • 按开始/结束日期查询。
  • 关键列：发送类型（0结算单、7用户资料…）、接收人、发送状态（成功 = 绿✓）、客户账号、标题、操作时间。
  • 发送状态：成功（绿✓）/ 发送中——"发送中"亦可能已成功送达，属正常状态。
提示需要重新发送时：勾选邮件 → 点击顶部【批量重发】。

4.5调整客户的交易平台与邮寄方法（分组客户）#

菜单位置：操作员管理 → 分组客户。客户的交易平台（归属哪个交易分组）和邮寄方法（结单及资料的寄送方式）都通过"把客户分配到对应分组"来管理。

界面三区

区域内容
左侧分组列表：流水号 / 分组编号 / 分组类型 / 分组名称 / 操作人（如分组类型 A(交易分组)，分组名称 SP、CQG、DlyMail…）
中间已分配客户——该分组当前包含的客户（客户账号 / 客户简称）
右侧未分配客户——尚未归入该分组的客户
底部分组编号 / 分组类型 / 分组名称 + 【增加】【删除】；两个列表下方为【分配】【取消分配】

操作

操作步骤
分配（客户归入分组）左侧选中目标分组 → 右侧"未分配客户"勾选客户 → 点下方【分配】
取消分配（客户移出分组）左侧选中目标分组 → 中间"已分配客户"勾选客户 → 点下方【取消分配】
新建分组底部填写分组编号、分组类型、分组名称 → 点【增加】
注意交易平台的分组名称与 2.1「交易中心」字段同源（SP → B、CQG → C）。动手前先确认分组类型，避免把客户错配到别的交易平台或别的邮寄方式。
